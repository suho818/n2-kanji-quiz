# JLPT N2 한자 기출 퀴즈

問題1(漢字読み) 347개, 問題2(表記) 350개, 問題3(単語形成) 119개 기출어휘(2000–2025)로 만든 4지선다 퀴즈.

- 읽기 모드: 한자 → 읽기 (장음·탁음·촉음 함정 보기)
- 표기 모드: 히라가나 → 한자 (모양·소리·뜻이 비슷한 한자로 만든 오답 보기)
- 단어형성 모드: （　）에 들어갈 앞말·뒷말 고르기 (같은 뜻이 되는 말은 오답에서 제외)
- 듣기 모드: 발음 → 한자
- 오답노트는 브라우저에 저장됨
- 한자 정보: 훈음·정자·획수, 음독/훈독, 이 단어에서 읽힌 방식(탁음화·촉음화), 같은 한자가 들어간 다른 기출어
